---
title: Colours
description: The web UI's colour palette, in light and dark, with the more vivid versions for wide-gamut screens.
---

The web UI's colours come from its [Groundwork](https://groundwork.timmo.dev) theme, `web/src/theme/triage.json`: zinc neutrals with an amber accent. The theme is solved into light, dark and Darker with every text and control colour meeting its contrast target, and the issue states' colours, from `web/src/theme/tones.ts`, are solved against each theme's surfaces the same way. The header's theme button switches between Triage and Snag, imports your own theme, and picks auto, light, dark or Darker.

Each `--triage-*` colour points at a theme role or a state's tone, shown in the "From" column. The swatches and values below are the Triage theme's, generated from `web/src/design.css` and `web/src/theme/themes.generated.css` by `mise run docs:gen`.

## What each colour means

| Token | Used for |
| --- | --- |
| `bg` | The page background |
| `surface` | Cards, tables, badges and buttons |
| `border` | Borders and skeletons |
| `text` | Body text |
| `muted` | Secondary text, labels and the times on event cards |
| `accent` | Links, pressed buttons, active filters and checkboxes |
| `new` | New issues, and the notice and info severities |
| `regressed` | Regressed issues, and the emerg, alert, crit and err severities |
| `ongoing` | Ongoing issues, and the warning severity |
| `quiet` | Quiet issues: a muted, slightly warm violet |
| `resolved` | Resolved issues |
| `muted-state` | Muted issues, and the debug severity |

`--triage-scrim` and `--triage-shadow` are black at 40% in every theme and mode.
